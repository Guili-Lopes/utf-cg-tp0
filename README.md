# Trabalho 1 - Computação Gráfica

Este projeto foi desenvolvido como meu primeiro trabalho da disciplina de **Computação Gráfica (CG)**.

O objetivo foi criar uma página web simples para apresentar um pouco sobre mim, incluindo algumas informações pessoais, interesses e experiências.

## Tecnologias utilizadas

- HTML
- CSS

## Objetivo

Praticar os conceitos iniciais de desenvolvimento web e criar uma página de apresentação pessoal de forma simples e organizada.
